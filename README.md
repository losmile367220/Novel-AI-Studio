- 人物列表縮短，手機一次可看到更多角色
- 搜尋人物
- 男主 / 女主 / 反派 / 配角 / 其他篩選
- 篩選列可橫向滑動，不再切到第一顆按鈕

- 基本資料 / 人物設定 / 能力與過去 / 人際關係 / 秘密 / 備註 分區
- 四步驟新增人物
